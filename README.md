# Tankar Game

Single-level retro tank battle game built with Next.js 16+, React, TypeScript, and HTML5 Canvas.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Controls

- Move: WASD or Arrow keys
- Shoot: Space
- Pause: P
- Mute: M
- Start/Restart: Enter

## Rules

- Player starts in the center.
- 4 normal enemy tanks stay active while enemies remain.
- Destroy 20 normal tanks to spawn the master tank.
- Master tank takes 20 bullet hits.
- Player has 3 lives.
- Each life survives 3 enemy bullet hits.
- Player bullets and enemy bullets neutralize each other.
- Brick walls are destructible.
- Stone and metal walls are solid.
